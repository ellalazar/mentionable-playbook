## Leave as-is (never translate)

- **Slash command names**: `/mentionable-article`, `/mentionable-audit`, etc. These are literal identifiers.
- **Brand / product names**: Mentionable, Claude Code, Cursor, Claude Desktop, ChatGPT, Perplexity, Gemini, Claude, Copilot, Grok, Google AIO / AI Mode, DataForSEO, Reddit.
- **Acronyms**: GEO, SEO, LLM, MCP, TL;DR, FAQ, JSON-LD, CTA.
- **Code blocks, file paths, env vars, JSON keys, URLs.**

## Rules

1. Translate prose into natural, idiomatic English, not word-for-word.
2. Preserve all markdown structure: headings, tables, links, code fences, frontmatter.
3. Anti-AI writing guidelines (`CLAUDE.md`) do **not** apply to repo documentation. Write clear, direct English.
